# Two Robots in an Elevator

One funny line of awkward small talk a robot says to another in an elevator, under 200 characters. A program that writes it to `/output/entry.txt` for the make.fun bounty [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f).

## How it works

Run `main.py` and it writes one line of awkward robot small talk, a single line of 1-200 characters, to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that is set).

```
python3 main.py
```
